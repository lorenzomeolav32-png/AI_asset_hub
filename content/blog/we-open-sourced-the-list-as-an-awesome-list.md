Every asset in this directory, all 123 of them, now also lives as a plain
markdown list on GitHub:
[awesome-claude-skills-mcp-servers](https://github.com/lorenzomeolav32-png/awesome-claude-skills-mcp-servers).

## Why bother, if the site already exists

Two different jobs. The site is where you come to check whether an asset is
actually worth installing: a last-verified date, a works-with matrix, and
copy-paste install steps for [Claude Skills](/claude-skills),
[MCP servers](/mcp-servers), Copilot agents, AI workflows and Cursor rules. The
GitHub list is for the people who live in GitHub search, who want to `git blame`
a README instead of loading a page, or who'd rather send a pull request than
fill out a form.

## How it stays in sync

The list is generated straight from the same content that powers this site, so
it's never manually copy-pasted out of date. When an asset gets added or
verified here, regenerating the list is one command away.

## Contributing

PRs are welcome on the GitHub list directly, same rules as
[submitting here](/submit): real open-source source, a permissive license, one
honest line about what it does.
